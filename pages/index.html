Инструкция

Изучите приложение перед началом использования.

1. Цветовая палитра

VMolberte "из коробки" предоставляет 72 уникальных цвета (вкладка "Цвета" в боковом меню). Вы можете:

  • Изменить эти цвета
  • Добавить новые цвета
  • Удалить любые цвета
Для изменения цвета плитки наведите курсор на прямоугольник внутри ( ) и нажмите ЛКМ, после чего Вы можете выбрать любой цвет палитры RGB.
Чтобы добавить новую плитку, Вам нужно навести курсор на любую из уже существующих плиток и нажать на появившийся символ "+";
Если Вы хотите удалить плитку, нажмите на крестик в правом верхнем углу ненужной плитки.

По умолчанию все внесённые Вами изменения "одноразовые" и будут стёрты после перезапуска приложения или повторного перехода на вкладку "Цвета". Для сохранения изменений воспользуйтесь соответствующей кнопкой. Для сброса изменений повторно откройте вкладку "Цвета" или нажмите кнопку сброса.

2. Загрузка данных

VMolberte поддерживает три формата данных:

  • CSV-файлы
  • TSV-файлы
  • Excel-файлы

Просто нажмите "Выбрать файл", укажите нужные, и приложение автоматически определит расширение и подготовит данные для работы.

VMolberte поддерживает открытие нескольких файлов, если они находятся в одной директории (можете попробовать и из разных, но у меня не получается).

N.B. Файл должен содержать минимум один столбец с категориальными данными для группировки и любое количество столбцов с метриками.

N.B. При работе с файлами Excel убедитесь, что листы не содержат объединённых ячеек и прочих свойственных только Excel'ю непотребств!!!

Если требуется открыть несколько файлов из разных директорий, делайте это последовательно, файл за файлом.

После успешной загрузки файла будет проиграна короткая анимация - подсветка полей выбора параметров синим цветом означает, что приложение распознало файлы и готово к работе.

3. Настройка параметров отображения

Блоки параметров отображения нужны для быстрой настройки визуализации:

  • Блок "Тип графиков и детали" содержит меню выбора графиков
  • Раздел "Раскрашиваем и группируем" содержит новую функцию - можно сгруппировать по одному столбцу, а раскрасить по другому
  • Блок "Метрики для визуализации" предназначен для указания имён колонок с данными для отображения
  • Блок "Сортировка" позволит заняться ручной сортировкой (см. следующий раздел)
  • Блок "Метаинформация" позволяет добавить к точкам на графике дополнительную информацию из выбранных колонок
  • "Дополнительные элементы" (линии, пороговые линии и др.) могут быть применены к графикам при отображении единичных метрик, но не в режимах отчёта.

4. Ручная сортировка групп

Ручная сортировка полезна в тех случаях, когда группы данных могут быть отсортированы только лексикографически:
Группы вида "1, 2, 3, ... 10" могут быть отсортированы числовой сортировкой, а группы вида "ABC, CBA, BAC" - только лексикографически.

Приложение автоматически определит тип (числа или буквы) для каждой группы и отсортирует их по мере возможности. При наличии смешанных типов ("1, 2, 3, 6, ABC, 7, 8, 10"), список будет приведён к виду "1, 2, 3, 6, 7, 8, 10, ABC" - текстовые значения помещаются в конец списка.

Если Вы не хотите перетаскивать блоки в режиме ручной сортировки, Вы можете создать файл с расширением "txt" и указать в нём нужный порядок групп через запятую: 

Группа 1,Группа 2,Группа 3,...,Группа Х

Для ручной сортировки:

  • Выберите столбец для группировки в соответствующем меню
  • В разделе сортировки появятся интерактивные блоки с именами групп
  • Перетаскивайте эти блоки (нажать кнопку мыши и удерживать) до достижения желаемого порядка групп
  • Если в данных есть группы, которые Вы хотите исключить из анализа, просто перетащите соответствующий блок в урну справа

N.B. Чтобы вернуть "выброшенные" блоки нужно повторно выбрать столбец для группировки.

P.S. Сортировка цветов влияет на порядок отображения цветов в цветовой легенде, но не влияет на порядок групп.

5. Генерация изображений

После настройки всех нужных параметров:

  • Нажмите кнопку "Нарисовать"
  • При работе с единичными метриками график отобразится в нижней части текущей страницы
  • При работе с отчётами результат будет вынесен в отдельную вкладку.

Время обработки зависит от объёма данных, но обычно всё происходит достаточно быстро.

6. Добавление деталей

После того как Вы отрисовали график по какой-либо метрике, Вам захочется приукрасить график дополнительными линиями. Для этого есть специальная вкладка "Дополнительные элементы", при нажатии на которую Вам раскроется небольшой ассортимент дополнительных опций.

N.B. Добавление линии p-value запускает длительный расчёт p-value по Манну-Уитни, основываясь на данных по оси Y: 


                            Python
                            from scipy.stats import mannwhitneyu
                            p_value = mannwhitneyu(data_1, data_2, method='auto', nan_policy='omit')
В результате работы функции на графике между заданными боксплотами через некоторое время появится линия с расчитанным p-value.

7. Экспорт результатов

После создания графиков (или отчётов):

  • Отдельные графики могут быть экспортированы с использованием функционала внутри графика - значок камеры в правом верхнем углу графика
  • Для экспорта отчёта на вкладке отчёта присутствует отдельная кнопка, сохраняющая отчёт в интерактивном виде
  • Делитесь визуализациями с друзьями и коллегами!

8. Стрельба по проблемам

Частые ошибки и решения:

  • Не определён разделитель: убедитесь, что Ваш файл имеет в качестве разделителя либо символ табуляции, либо запятую
  • Странный размер графика в отчёте: измените ширину окна приложения (откройте на весь экран или наоборот - уменьшите масштаб).

При возникновении ошибок: пишите в telegram (@sxotoffefs) или на GitHub.
